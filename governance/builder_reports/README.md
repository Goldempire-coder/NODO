# Builder Reports

Aqui se guardan los reportes producidos por Builder.

Formato recomendado:

```txt
YYYY-MM-DD_slice_XX_builder_report.md
```

Cada reporte debe incluir:

- slice asignado
- resumen de trabajo
- archivos cambiados
- lineas cambiadas
- contratos cumplidos
- tests ejecutados
- tests no ejecutados
- riesgos residuales
- estado final
