# COPY_RULES.md

Usar lenguaje humano, preventivo y claro. No usar claims financieros absolutos. No mostrar errores tecnicos al usuario.

## Regla central

NODO registra negocios, ofertas, ordenes, chat, evidencia, reputacion y creditos internos. El pago y la entrega entre cliente y negocio ocurren directamente entre las partes.

## Evitar

- enviar dinero
- remesa
- cambiar dinero
- pago seguro
- entrega garantizada
- negocio seguro
- fondos protegidos
- saldo en NODO
- custodia
- escrow
- liberar fondos

## Preferir

- que monto buscas
- ofertas disponibles
- condiciones publicadas
- metodo publicado
- entrega acordada
- verificar ingreso
- marcar entrega realizada
- perfil registrado
- historial disponible
- soporte operativo

## Creditos

Los creditos NODO son internos para servicios propios de la plataforma. No son dinero, deposito, saldo custodiado, retiro disponible ni valor transferible.

USDC real/mainnet no debe presentarse como activo para piloto hasta aprobacion Owner separada de crypto production go-live. Staging/testnet debe decir Base Sepolia/testnet cuando aplique.

## Nombres tecnicos heredados

El codigo, tablas o endpoints pueden conservar nombres internos como `remitter`, `payment_reported` o `payment_instructions` por compatibilidad. Esos nombres no autorizan copy publico de remesa, envio de dinero, pago garantizado, custodia o procesamiento financiero por NODO.
