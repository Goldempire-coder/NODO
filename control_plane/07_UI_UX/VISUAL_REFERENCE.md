## Visual personality

NODO should feel:

- fintech
- dark premium
- native inside Telegram
- fast
- trustworthy
- compact but readable
- operational, not marketing

NODO should not feel:

- generic web landing page
- crypto casino
- blockchain/web3 dashboard
- playful game
- beige/soft SaaS
- overloaded admin ERP

## Required visual characteristics

- dark navy app background
- subtle radial depth, no decorative blobs
- translucent dark surface cards
- thin cool borders
- green trust accents
- blue action accents
- purple only for Zelle/secondary emphasis
- rounded mobile cards, but not cartoonish
- strong amount typography
- compact marketplace cards
- verified badges visible
- bottom tab navigation on user-facing app
- clear active tab state
- controlled premium motion
- animated logo on entry/home

## Prohibited visual patterns

- fake production metrics
- "Mas cercano" filter in MVP
- city/location UI in MVP
- escrow/protected-funds language
- full landing page hero
- decorative blobs/orbs
- oversized marketing cards
- white generic web form as primary app style
- inconsistent logo treatment
- static-feeling first screen
- heavy decorative animation
