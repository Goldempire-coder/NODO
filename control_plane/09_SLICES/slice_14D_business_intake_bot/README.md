# slice_14D_business_intake_bot

Contrato para construir el Bot Registro Negocios como superficie separada.

El bot captura negocios referidos/interesados, crea solicitudes pendientes y guarda evidencia privada para revision admin. No aprueba negocios, no da acceso a Mini App Negocio, no crea anuncios, no acredita creditos y no convierte usuarios en negocio operativo.
