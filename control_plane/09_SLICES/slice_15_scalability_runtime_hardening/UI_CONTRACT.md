# UI_CONTRACT.md

## Pantallas

No se construyen pantallas nuevas.

## Cambios UI permitidos

Solo si la medicion demuestra impacto:

- reducir llamadas duplicadas al marketplace.
- evitar cargar marketplace repetidamente al cambiar tabs.
- debounce de inputs de monto.
- conservar resultados visibles mientras se refresca.
- estados de loading mas suaves.

## Prohibido

- Redisenar pantallas.
- Cambiar copy aprobado.
- Reintroducir negocio/admin en Mini App Cliente.
- Cambiar identidad visual NODO.
- Agregar promesas de garantia, escrow o fondos protegidos.
