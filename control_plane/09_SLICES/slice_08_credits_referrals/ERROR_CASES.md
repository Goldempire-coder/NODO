# ERROR_CASES.md

Errores esperados:

- INVALID_PACKAGE
- INVALID_PAYMENT_METHOD
- PURCHASE_NOT_FOUND
- PURCHASE_STATUS_INVALID
- STRIPE_SIGNATURE_INVALID
- STRIPE_WEBHOOK_DUPLICATE
- STRIPE_SESSION_INVALID
- MANUAL_PAYMENT_PROOF_REQUIRED
- MANUAL_PAYMENT_ALREADY_REVIEWED
- ADMIN_REASON_REQUIRED
- CREDIT_ALREADY_GRANTED
- CREDIT_BALANCE_INSUFFICIENT
- CREDIT_WALLET_NOT_FOUND
- REFERRAL_NOT_ALLOWED
- REFERRAL_ALREADY_USED
- REFERRAL_CODE_NOT_FOUND
- REFERRAL_CAP_REACHED
- FOUNDER_ACCESS_EXPIRED
- IDEMPOTENCY_KEY_REQUIRED
- IDEMPOTENCY_PAYLOAD_MISMATCH
- FORBIDDEN
- RATE_LIMITED
- VALIDATION_ERROR
- UNAUTHENTICATED

Reglas:

- Usar `06_API_CONTRACTS/ERROR_CONTRACT.md`.
- No exponer stack traces, SQL, Stripe secrets, tokens, signed URLs ni storage keys.
- Permission errors no deben filtrar existencia de recursos privados.
- Errores de pago no deben prometer acreditacion si falta webhook o approve admin.
