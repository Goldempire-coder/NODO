# operations/evidence

Guardar aqui evidencia operacional que no pertenezca a un slice especifico.

No incluir secretos, tokens, signed URLs completas, documentos privados ni datos personales innecesarios.

Formato recomendado:

- `YYYYMMDD-HHMM-<tema>.json`
- `YYYYMMDD-HHMM-<tema>.md`

Si la evidencia corresponde a stress, migrations o staging tooling, tambien puede guardarse en `evidence/slice_runs/`.
